## Description

This is the Software Development rotation, and it is not a coding bootcamp crammed into five days. You are not here to memorize syntax or to finish the week calling yourself a developer. You are here to find out what it feels like to solve a problem you already have — the outreach engine you have been running since Week 1 — by writing a short program instead of doing the work by hand. Code is another lever on the same machine.

Everything you write this week operates on your own data: your contact list, your pipeline, your follow-up queue. In the first lab you will build the vocabulary — variables, functions, loops, arrays and objects — by making a TypeScript file answer real questions about your contacts. In the second you will learn what an API actually is and wire your script up to a live source, whether that is a CSV your CRM exports or an endpoint it serves. In the third you will put the whole thing under version control and publish it.

You are paired with a current CCC software apprentice for the week, so when you get stuck you are getting unstuck by someone who was where you are not long ago. Roughly twenty hours of this rotation are live lab time, and these lessons are the documents you keep open while you work. The milestone is concrete and public: a working script published to GitHub with a README a non-programmer can read and run. That repository is yours to show an employer.

## Objectives

- Apply core programming concepts to contact-list tasks in TypeScript
- Explain what APIs are and use a script to pull and transform pipeline data
- Use Git fundamentals and publish working code to GitHub with a plain-language README
