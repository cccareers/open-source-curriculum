## The monitor's test

A monitor reads your file months later, with no access to you and no memory of the participant. The test for an eligibility case note is simple: **could a stranger reach the same determination from what you wrote and what's in the file?** If they would need to call you, the note has failed, even if your decision was right.

Monitors usually ask the same questions, in roughly the same order:

1. Which program and which category?
2. What evidence supports each element, and where is it?
3. Where did staff use judgment, and why?
4. Was anything self-attested, and was that allowed?
5. What priority status was recorded, if any?
6. Who decided, and when?

A good eligibility case note answers all six in that order.

## A structure you can reuse

Keep it short. A strong eligibility note is often under 200 words. Use the same order every time so reviewers know where to look.

```text
ELIGIBILITY DETERMINATION – [Program], [Category]
Date determined: [date]   Staff: [name/title]

Elements and evidence:
- [Element]: [Yes/No] – [document name], [date on document], [where filed]
- ...

Judgment calls:
- [Element]: [reasoning in 1–3 sentences, sources relied on]

Self-attestation: [None / element(s), reason, sources tried, form date]
Work authorization: [verified per WSD18-03 / not required – reason]
Priority of service: [tier and basis, or N/A for this program]
Local policy relied on: [policy name/version, if any]
```

The template uses square-bracket placeholders. Replace every one. A bracket left in a saved note is a quality-control flag.

## Write facts, not conclusions

| Weak | Strong |
| --- | --- |
| "Client is a DW." | "Dislocated Worker, laid-off category. Separation letter from Foothill Family Clinic dated 1/10, scanned to eligibility folder." |
| "Unlikely to return to industry." | "Unlikely to return: employer letter states billing function permanently outsourced; regional LMI shows declining in-house billing openings (report dated 2/1, in file)." |
| "Docs verified." | "UI claim record reviewed 2/14; DD-214 reviewed 2/14; copies in file." |
| "Priority: yes." | "Adult priority Tier 2 (not a veteran; CalFresh recipient, county verification 2/14)." |

The pattern is the same in every row: name the document, its date, and where it lives. State the reason for any judgment.

## Worked example: Marcus, a separating service member

**Weak note:**

> Vet, getting out of Army soon. DW eligible. Docs in file.

**Strong note:**

> ELIGIBILITY DETERMINATION – Dislocated Worker, separating service member category (confirm category definition against current WSD24-04)
> Date determined: 5/6. Staff: J. Rivera, Eligibility Technician.
> Elements and evidence: Separation from active duty documented by [document type per current Acceptable Documentation List], dated 4/28, in eligibility folder. Age 26, verified with CA driver's license 5/6.
> Judgment calls: None.
> Self-attestation: None.
> Work authorization: U.S. citizen; verified with U.S. passport 5/6 per WSD18-03.
> Priority of service: N/A for Dislocated Worker enrollment. Veteran status recorded for reporting.
> Local policy: none relied on.

The strong note leaves one bracket on purpose: the exact separation document depends on the current list. In a real note you would name it.

## Self-check before you save

- [ ] Program and category named in the first line
- [ ] Every element has a document, a date, and a location
- [ ] Each judgment call has a reason and a source
- [ ] Self-attestation, work authorization, and priority are each addressed, even if the answer is "none" or "N/A"
- [ ] No placeholders left, no rescinded guidance cited
- [ ] Your name and the determination date are on it

## Practice

1. Rewrite this note using the structure above. Invent reasonable fictional details where needed and mark them as invented:

   > Youth OSY. Low income. Has barrier. Self-attested some stuff. Enrolled.

2. Swap notes with a partner (or a breakout-room group). Read theirs as a monitor would and write down every question you would still need to ask. Each question is a gap. Then revise your own note until your partner has no questions.
