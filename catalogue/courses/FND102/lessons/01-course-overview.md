## Description

Most monitoring findings start at eligibility: a missing document, a category that does not quite fit, or a case note that leaves the reviewer guessing. The state Technical Assistance Guide (WSD24-04) settles a lot, but it leaves real judgment calls to you, and this course is about making those calls well and leaving a file that shows how you made them.

You will work through the decisions you face at intake, including Dislocated Worker categories, "unlikely to return," self-attestation, low income, Selective Service, Youth school status, priority of service, and work authorization. You will practice on realistic fictional cases, including separating service members and apprentices.

By the end you should be able to decide eligibility on a hard case, document it with the right evidence, and write a case note that a monitor can follow without calling you to ask what you meant.

## Objectives

- Apply Adult, Dislocated Worker, and Youth eligibility criteria to complex cases using the Acceptable Documentation List.
- Determine when self-attestation is permitted and document it correctly.
- Apply the priority-of-service order (WSD24-06, WSD24-15) and record status at eligibility.
- Identify when work authorization must be verified under WSD18-03 now that federal TEGL 10-23 Change 2 has been rescinded.
- Write an eligibility case note that a monitor can follow without asking questions.
