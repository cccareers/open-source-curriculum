## Description

Every page a QA engineer tests is built out of HTML and CSS, whether or not anyone hands you the source. Before you can write a reliable test, click a button with confidence, or describe a layout bug so a developer can reproduce it, you need to read a page the way it was built: as structured markup with styling rules layered on top.

This course teaches HTML and CSS from that angle. You will learn to write semantic markup and labelled controls that are easy to locate and automate, to use CSS selectors and the box model to understand why an element renders where it does, and to build a responsive layout you can pressure-test at different screen sizes.

By the end, you will look at a live page and be able to say precisely what is wrong with it and why, in terms another engineer can act on. That skill of turning "this looks broken" into a reproducible defect report is the throughline of everything ahead.

## Objectives

- Write semantic HTML that gives a page a testable, accessible structure
- Use common page elements such as text, links, media, and tables correctly
- Apply CSS selectors, the cascade, and the box model to control page layout
- Build a responsive layout and check it against basic accessibility expectations
- Inspect a rendered page and describe what is wrong with it in reproducible terms
