## Description

This course teaches you the data structures and algorithms every working developer relies on, but it teaches them with an eye toward testing. Every technique here doubles as a way of reasoning about how software can fail and how you would prove that it works.

You will start by breaking problems into steps a computer can follow, then move into the structures JavaScript gives you for holding data, and use those structures to implement and compare search and sort strategies. Along the way you will see how the same reasoning that makes an algorithm correct also tells you where to look when something breaks and what data to choose when you test a change.

By the end, you will be able to walk a tree or graph to trace a failure back to its source, and use complexity and edge-case reasoning to design test data before validating a change.

## Objectives

- Decompose a problem into steps a computer can follow
- Choose a data structure that fits the data you are holding
- Implement and compare linear and binary search
- Implement a sort and explain what it costs
- Traverse a tree or graph structure
- Use complexity and edge-case reasoning to design test data
