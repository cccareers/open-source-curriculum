## Description

When an employer tells you they want to "do apprenticeship," the next question is almost always how long it will take to get registered. Most AJCC staff have never been shown how registration with California's Division of Apprenticeship Standards (DAS) actually works, so the answer often ends up being a guess.

In this live-virtual session you will walk through what a sponsor submits to register a program and an apprentice, which advisory body oversees a given program, and why the path can take months rather than weeks. You will also learn to spot when joining an existing intermediary program gets an employer's apprentices started sooner than building a new program from scratch.

You will finish by drafting a registration roadmap for a sample employer that you can use as a model for the next real conversation you have with a business partner.

## Objectives

- Outline the steps and documents required to register a new program and an apprentice.
- Determine which advisory body has jurisdiction over a program.
- Set an accurate timeline expectation with an employer.
- Decide when to use an existing intermediary program instead of registering a new one.
