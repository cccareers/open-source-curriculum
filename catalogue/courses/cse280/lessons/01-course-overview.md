## Description

By the time you reach this course you can build things in a cloud account, watch them run, and fix them when they break. This course is about a different question, and it is the one that decides whether the thing you built is allowed to hold the data it holds: can you prove it is configured the way someone promised a customer, a regulator, or an auditor it would be?

You will learn to read an obligation written in someone else's language — a contract clause, a security questionnaire, a framework requirement — and turn it into a specific setting in a cloud account that can be checked, along with the record that proves it was set that way for the whole period and not only on the day someone looked. That translation is the heart of the work, and it is what separates an engineer who can be trusted with a regulated workload from one who cannot.

This is a practitioner's course, taught from a support engineer's seat. It is not legal training and it does not prepare you for a compliance certification exam. A large part of the skill is knowing which questions are yours to answer and which belong to a compliance officer or a lawyer, so you will practise routing as deliberately as you practise configuring. Everything you produce here is an artifact somebody else can use: a mapping, a finding, a restore record, a policy page, a training session.

## Objectives

- Explain how the shared responsibility model divides compliance obligations between a cloud provider and its customer
- Distinguish SOC 2, HIPAA, GDPR, and NIST by what each governs and who it applies to
- Map a written compliance requirement to a specific, testable cloud control
- Govern identity and access at organization scale using least privilege and periodic review
- Protect data with encryption, classification, and residency controls appropriate to its sensitivity
- Conduct a periodic security audit and drive its findings to remediation
- Design a cloud architecture that meets a stated recovery time and recovery point objective
- Implement and verify backup and restoration procedures
- Write policy, runbook, and evidence documentation an auditor can follow
- Deliver a compliance training session to a technical or non-technical audience

## Prerequisite Knowledge

- Completed Introduction to Cloud Computing (cse101) or equivalent working knowledge of cloud service models and IAM
- Completed Cloud Infrastructure Deployment & Management (cse203) or equivalent experience with cloud networking and storage
- Completed Monitoring, Troubleshooting, & Incident Response (cse220) or equivalent incident-handling experience
