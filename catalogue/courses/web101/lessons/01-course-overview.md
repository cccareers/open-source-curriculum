## Description

Every automated test you will ever write walks the same structure a browser builds when it loads a page. This course teaches you that structure from the inside: JavaScript in the browser, the Document Object Model it manipulates, the events a user (or a test script) fires at it, and the asynchronous requests that make modern pages unpredictable to verify.

You will not be building production features here. You are learning the runtime you will spend your career testing, so that when a page misbehaves you can say exactly what broke, where, and why, instead of just "it doesn't work." The debugger you learn to use in this course is the same instrument you will reach for on the job to turn a vague bug report into a defect that can actually be filed and fixed.

By the end, you will build a small interactive page yourself, then deliberately verify it against its own expected behavior and record what fails — because a QA engineer who has never broken something on purpose does not yet know what breaking looks like.

## Objectives

- Use JavaScript variables, functions, and control flow in the browser
- Select and modify DOM nodes with the standard browser APIs
- Handle user events while keeping interactive behaviour reachable from the keyboard
- Validate form input and report errors to the user clearly
- Fetch data asynchronously and handle the failure cases
- Debug a broken page in the browser and describe the defect precisely

## Prerequisite Knowledge
