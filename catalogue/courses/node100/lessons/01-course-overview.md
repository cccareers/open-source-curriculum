## Description

Node lets you run JavaScript outside a browser, straight from the command line, and that is exactly where a QA engineer lives: writing small scripts and tools that check whether other programs behave the way they should. This course teaches you the core language, one building block at a time, always with an eye toward code you will eventually have to test rather than code you are shipping to a user.

You will start by running your first script and learning how Node keeps track of values, then move through the decisions, repetition, and functions every program is built from. Along the way you will practice writing small, predictable pieces of logic instead of one long tangled script, because small pieces are what make testing possible in the first place.

By the end, you will use Node's built-in `assert` module to write a short script that checks another program's behavior automatically — your first real step into the automated testing tools a QA engineer builds and relies on every day.

## Objectives

- Run JavaScript with Node and declare variables with the right scope
- Express decisions with conditional operators and boolean logic
- Repeat work with the looping constructs Node provides
- Break a larger problem into small, independently testable functions
- Model data with objects and arrays
- Write a small assertion script that checks another program's behaviour

## Prerequisite Knowledge

- web101 JavaScript in the DOM, or equivalent comfort reading and writing small JavaScript programs
