## Description

Everything you have learned so far in this pathway has been about keeping bad things from happening. This course is about what you do once one already has. An alert fires, a user reports something odd, a partner sends you a warning — and from that moment the work is no longer prevention. It is figuring out what happened, proving it with evidence, stopping it without making it worse, and being able to explain all of it afterwards to people who were not in the room.

You will work the way a real responder works: from the alert queue inward. You will learn to decide which alerts are worth a human, how to characterize an attacker's behavior from the traces they leave, how to write down what you find so it still means something a month later, how to collect host and network evidence without destroying it, how to safely study a suspicious file in an isolated lab, and how to choose the containment action that ends the incident without ending the business day. Three projects give you the three artifacts a real case produces: a triage timeline, an evidence handling record, and a report to management.

This is blue-team work from beginning to end. Every sample you touch is supplied by your instructor and analyzed inside an isolated lab virtual machine that has no route to a production network. You will never write, modify, or deploy malicious code in this course, and you will never test anything against a system you do not own. The skill being built here is the defender's skill: observe carefully, preserve faithfully, decide deliberately, and report honestly.

## Objectives

- Walk an incident through preparation, detection, containment, eradication, recovery, and lessons learned, naming the decision made at each handoff
- Triage an alert queue and decide which alerts become incidents
- Use indicators of compromise and an adversary behavior framework to characterize what an attacker did
- Document an incident timeline and preserve evidence so that it survives later review
- Collect and analyze host and network artifacts without altering the evidence
- Analyze a suspicious file in an isolated lab environment and extract indicators to hunt with
- Choose containment, eradication, and recovery actions that stop an incident without destroying evidence or the business
