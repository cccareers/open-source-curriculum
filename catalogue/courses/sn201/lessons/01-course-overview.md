## Description

Up to now you have been a user of applications someone else built. In this course you become the person who builds them. You will take a real business problem — a team that tracks its work in a spreadsheet and an inbox — and turn it into a scoped ServiceNow application with its own tables, forms, logic, automation, and security, then package that application so it can move from your development instance to a test instance and on to production.

The work follows four verbs in order: design, build, develop, deploy. You scope and create the application first, then design the data it stores, then build the interface people actually touch, then develop the logic and automation that make it behave, then lock it down with roles and access rules, and finally move it. Each lesson leaves you with something that runs, so by the last lesson you are packaging an application you have used, not a diagram you have drawn.

This is low-code development. You will write some script, because an application always needs a little, but the scripts here are short and single-purpose — a business rule that stamps a field, a client script that hides one control. Learning to design script libraries, server-side APIs, and reusable classes comes later in the pathway. Your job in this course is to know which platform tool solves which problem, and to reach for script only when configuration genuinely cannot do the job.

## Objectives

- Scope a custom application and create it with App Engine Studio
- Design an application data model using tables, fields, and table extension
- Build forms, views, and UI policies that present the right fields to the right user
- Add application logic with business rules and client scripts
- Automate an application process with Flow Designer
- Secure an application with roles and access control rules
- Move an application between instances using update sets and source control
