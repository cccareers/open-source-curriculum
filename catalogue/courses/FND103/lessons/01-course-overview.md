## Description

In California, case-management practice is set almost entirely at the local level, and it is where staff turnover hurts most. When a case manager leaves, the participant file is the only record of what was planned, what happened, and why. This course is about making that file strong enough to stand on its own.

You will practice turning an objective assessment into an Individual Employment Plan (or a Youth Individual Service Strategy), writing case notes that document progress instead of opinion, and setting activity dates that match what actually happened. You will also learn to spot the documentation errors that monitors and validators keep finding, so you can catch them in your own files before anyone else does.

The course closes with a hands-on project in which you repair a sample participant file so it would pass a validation review.

## Objectives

- Write an IEP that documents interest, aptitude, and skills for a training or OJT placement.
- Write case notes that are factual, timely, and tied to an activity code.
- Set activity begin and end dates from provider attendance, not vouchers, and avoid system auto-closure.
- Recognize the recurring documentation errors that fail Data Element Validation.
