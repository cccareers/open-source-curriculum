## Description

You already know how to build a page with HTML, style it with CSS, and make it move with JavaScript. That approach stops scaling somewhere around the third screen, when the same markup exists in four places, when a change to one part of the page silently breaks another, and when you can no longer answer the question "what is on screen right now?" without reading every line you wrote. React exists to answer that question. You describe what the interface should look like for a given set of data, and the library takes responsibility for making the screen match.

This course is a hundred hours of building that skill on real code. You will start by taking an interface apart on paper and naming its pieces, then learn how data travels between those pieces, how a piece remembers something, how a screen renders a list or hides a section, how a form captures what a person types, and how a component loads data from a server it does not control. Each of those is a place where beginners form a wrong mental model that costs them weeks later, so each one gets its own lesson and its own lab.

The last third of the course is about the judgment that surrounds the code. You will build an interface that works with a keyboard and on a phone, prototype a feature two different ways before committing to one, and take a written plan apart into an increment you can actually deliver. The course ends with an application you build yourself and then stand up and explain to other people, because a developer who cannot walk a team through their own work is only half useful.

## Objectives

- Break an interface into a tree of reusable components
- Pass data through a component tree with props and composition
- Manage component state and respond to user events
- Render lists and conditional interfaces correctly
- Build forms with controlled inputs
- Load and display remote data from a component
- Build interfaces that are accessible and responsive
- Prototype a feature before committing to an implementation
- Work from a project plan to deliver a feature increment
- Present a working React application and the reasoning behind it

## Prerequisite Knowledge

- Completed JavaScript Projects (web102) or equivalent
- Comfortable with modern JavaScript: arrow functions, destructuring, array methods, and modules
- Working knowledge of HTML and CSS
