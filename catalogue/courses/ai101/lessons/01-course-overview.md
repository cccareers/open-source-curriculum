## Description

You are about to spend a lot of your working life talking to machines that answer in fluent English. Getting useful work out of them is a learnable skill with a shape: understand what the thing actually does, ask for what you want in a form it can act on, check the answer before you trust it, and automate the parts that repeat. That is what this course teaches, in that order.

Nothing here assumes you have written code or studied AI before. You will start with a plain-language mental model of how a generative model turns your words into a response, so that when a prompt disappoints you can reason about why instead of guessing. From there you will build prompts deliberately rather than by feel, vary the technique to match the job in front of you, and stack prompts together when one request is not enough.

The last third of the course is about trust and reach. You will learn to judge an answer for accuracy, relevance, and bias, and to do something specific with what that judgment tells you. Then you will send the same kind of request to a hosted model from a short script, watch the tokens and the cost add up, and learn to tell the difference between a problem a better prompt solves and one that needs a tuned model. Every exercise is something you can run yourself in a browser or a text editor.

## Objectives

- Explain in plain language how a generative AI model turns a prompt into a response, and what a token, a context window, and a temperature setting each control
- Describe what current generative models are reliably good at, where they fail, and how to choose a model for a task
- Write a structured prompt using role, task, context, constraints, and output format
- Adapt prompting technique to the task type, including text generation, summarization, extraction, and image creation
- Apply few-shot examples and multi-step prompt chains to tasks a single prompt cannot do well
- Evaluate an AI response for factual accuracy, relevance to the request, and bias, and act on what the evaluation shows
- Call a hosted model API from a simple script and describe when fine-tuning or a tuned system prompt is the right adaptation

## Prerequisite Knowledge

- No prior AI or programming coursework is assumed
- Comfort using a web browser, a text editor, and a spreadsheet
