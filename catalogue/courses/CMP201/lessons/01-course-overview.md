## Description

Every year, EDD checks whether the numbers your local area reports are backed by what is actually in participant files. That review, Data Element Validation, does not ask whether you served people well. It asks whether you can prove what the system says, with the right document, inside a short window.

In this live-virtual session you will learn how files are picked and how elements are scored, which documents support the elements that fail most often, and how to catch problems yourself every month instead of once a year. You will also practice fixing errors the proper way, so a correction strengthens the record rather than creating a new finding.

You will leave with a self-audit routine you can run on Monday, whether you carry a caseload, supervise a team, or administer your area's data.

## Objectives

- Explain how DEV samples files and scores elements.
- Match each commonly failed element to its acceptable source documents.
- Run a monthly file self-audit using a CCC checklist.
- Correct errors through the proper Data Change Request process before the annual report.
