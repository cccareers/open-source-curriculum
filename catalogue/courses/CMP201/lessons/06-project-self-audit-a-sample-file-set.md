## Goal

Run one month's self-audit on a small fictional file set for Valley Regional Workforce Board. Match each element to its source document, log the results, calculate element error rates, and route every correction through the right path, including at least one Data Change Request.

## The case

You are the MIS administrator at Valley Regional's Riverside AJCC. This month's random draw pulled four files. All participants and details are fictional.

| File | Program | Status | Element | System value | Document in file |
| --- | --- | --- | --- | --- | --- |
| A: Maria R. | Dislocated Worker | Open | Date of birth | 04/12/1984 | Driver's license, 04/12/1984 |
| A | | | Dislocated worker status | Layoff 06/30 | Employer letter, layoff 06/30 |
| A | | | Training begin date | 08/01 | Voucher dated 08/01; roster shows first attendance 08/19 |
| B: Dev P. | Adult | Exited, reported | Credential attained | Certified Phlebotomy Technician | Certificate reads "Certified Phlebotomy Technician" |
| B | | | Employment status at entry | Not employed | Signed self-attestation |
| B | | | Exit date | 03/31 | Case note, last service 03/31 |
| C: Lena T. | Youth | Open | Highest grade completed | High school diploma | None in file |
| C | | | Date of birth | 11/02/2006 | Birth certificate, 11/20/2006 |
| D: Sam K. | Adult | Exited, reported | Training begin date | 01/09 | Provider roster, first attendance 01/09 |
| D | | | Credential attained | Commercial driver's license, Class A | Copy of license in file shows Class B |

## Requirements

1. Complete the CCC self-audit checklist from lesson 4 for each file, using only the elements listed.
2. For every element, state the acceptable document types from the current WSD22-15 list and give a verdict: pass, fail, or check.
3. Build a results log and calculate the error rate for each element across the set.
4. For every fail, choose the correction path (direct edit with note, Data Change Request, or obtain document) and write the case note or request summary.
5. Write a five-sentence memo to your supervisor naming the pattern you see and one process change.

## Constraints

- Use only the facts given. Do not assume a document exists if the table doesn't list it.
- Where your verdict depends on whether self-attestation or a case note is allowed for an element, cite the WSD22-15 entry you checked, or mark it "check" with the question you would ask.
- No fabricated or backdated documents in any proposed fix.

## Definition of done

- Four completed checklists and one results log.
- Every element has a verdict tied to a named acceptable document type.
- Error rates are calculated per element, with any element over the 10 percent threshold flagged.
- Every fail has a correction path, and every error on a closed, reported record has a Data Change Request summary.
- The memo names a cause, not just a count.

## Hints

- File A's training date is the same voucher-versus-roster problem from earlier lessons.
- Read File C's dates carefully, digit by digit.
- File D is closed and reported. Ask whether the system value or the document is wrong before you choose a path.
- With only ten elements, each failure moves an error rate a lot. Say so in your memo.
