## Concept and misconception it fixes

Misconceptions: (1) the "difficult client" is choosing to be difficult; (2) the agreeable client who says yes to everything is doing well. The animation shows one intake moment replayed four times, with the same trigger (being asked about a past clinic) producing four different protective responses — and shows the CHW response that restores safety and choice in each case. The fawn response is highlighted because it looks like an ideal client.

## Visual language

- Flat, warm illustration. Client is a neutral silhouette with expressive posture; CHW is a second silhouette across a small table.
- A small "safety meter" arc above the client (text labels "less safe" ↔ "more safe") instead of color alone; the arc fills in steps.
- Response labels appear as text tags: FIGHT, FLIGHT, FREEZE, FAWN, each with a distinct icon (raised hand, door, pause symbol, nodding head).
- Palette: Okabe-Ito blue #0072B2 and orange #E69F00 on cream background; all states labeled in text.

## Interaction variant

A step-through H5P interactive video: at the moment each response appears, the learner chooses among three CHW lines (one that defends or pushes, one that ignores, one that restores choice). Feedback explains which trauma-informed principle each choice supports or undermines.

## Production notes

- Avoid depicting any specific trauma; the trigger is only "a past clinic."
- Cultural note on screen in scene 10: reduced eye contact can be respect, not withdrawal.
- Silhouettes should not code any response to a race, gender, or age.
- Pair with Lesson 5, Practice 1 ("Read the cues").
