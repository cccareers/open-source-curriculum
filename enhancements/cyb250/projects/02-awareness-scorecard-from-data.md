## Scenario

Merrow Fields Logistics has run two quarters of its awareness program. The manager who built the "bad dashboard" in lesson 05's Practice Part 4 has exported the raw data and asked you to produce the board scorecard properly this time. You have three synthetic CSV files: simulation events, real reported messages, and a staff roster. You will compute the metrics from lesson 05 with the **correct denominators**, segment by audience, state difficulty alongside every simulation number, and write the one-page scorecard. A small script checks your numbers.

## Scope and authorization

- All data is **synthetic** and generated by the script below. It describes fictional people at a fictional company.
- Do not use real simulation results from an employer for this exercise. If you later build a real scorecard, follow lesson 04's data-minimization rules: aggregate and cohort results only; no individual names leave the triage team.
- Nothing is sent to anyone. This project analyses data; it does not run a simulation.

## What you will build / produce

1. `scorecard.py` — reads the three CSVs and writes `metrics.json` with the fields listed under Automated checks.
2. A one-page scorecard (Markdown or PDF) built from `metrics.json`, with the narrative section from lesson 05 ("what changed, what it means, what the numbers do not prove, the decision you need").
3. A short method note: each metric's definition, denominator, source, leading/lagging.

## Before you start

- Lesson 05 "Measurement: what to count and what not to", and lesson 04's simulation ethics.
- Python 3.9+ (standard library only; `pandas` optional).
- Generate the data: save and run `make_data.py`.

```python
# make_data.py — synthetic data, fixed seed so everyone gets identical files
import csv, random
random.seed(250)
aud = ["head_office"]*90 + ["depot"]*310 + ["field"]*40 + ["contractor"]*40
with open("roster.csv","w",newline="") as f:
    w=csv.writer(f); w.writerow(["staff_id","audience","has_mailbox","on_leave_q2"])
    for i,a in enumerate(aud):
        w.writerow([f"S{i:03d}",a, "yes" if a in ("head_office","field") else "no",
                    "yes" if random.random()<0.05 else "no"])
# Simulations go only to mailbox holders; depot and contractor staff have no corporate mailbox, so they are not simulated.
with open("sim_events.csv","w",newline="") as f:
    w=csv.writer(f); w.writerow(["campaign","quarter","difficulty","staff_id","delivered","clicked","reported","minutes_to_report"])
    for q,camp,diff,pc,pr in [("Q1","C1","easy",0.12,0.18),("Q2","C2","hard",0.20,0.34)]:
        for i,a in enumerate(aud):
            if a not in ("head_office","field"): continue
            delivered = "yes" if random.random()>0.04 else "no"
            clicked = "yes" if delivered=="yes" and random.random()<pc else "no"
            reported = "yes" if delivered=="yes" and random.random()<pr else "no"
            mins = random.randint(2,240) if reported=="yes" else ""
            w.writerow([camp,q,diff,f"S{i:03d}",delivered,clicked,reported,mins])
with open("real_reports.csv","w",newline="") as f:
    w=csv.writer(f); w.writerow(["quarter","report_id","malicious","first_report_for_campaign","detected_first_by"])
    for q,n,mal in [("Q1",140,18),("Q2",210,22)]:
        for k in range(n):
            m = k < mal
            w.writerow([q,f"{q}-{k}", "yes" if m else "no", "yes" if m and k%3==0 else "no",
                        ("human_report" if k%2==0 else "gateway") if m and k%3==0 else ""])
```

## Milestones

1. **Explore (45 min).** Load the files. Before computing anything, write down which rows belong in each denominator (delivered, not sent; exclude staff on leave in the quarter they were on leave).
2. **Compute (1.5 h).** Implement `scorecard.py`. Required `metrics.json` keys, each a dict keyed by quarter (`"Q1"`, `"Q2"`):
   - `difficulty` — the campaign difficulty tier.
   - `report_rate` — reported ÷ delivered (excluding on-leave staff in Q2).
   - `click_rate` — clicked ÷ delivered (same denominator).
   - `report_rate_among_clickers` — reported and clicked ÷ clicked.
   - `median_minutes_to_report` — median of `minutes_to_report` for reporters.
   - `real_reports` — count of real reported messages.
   - `real_malicious_share_first_detected_by_human` — among rows with `first_report_for_campaign == yes`, the share where `detected_first_by == human_report`.
   - `simulation_coverage` — share of the whole roster that received a simulation (shows the depot and contractor gap).
3. **Interpret (1 h).** Q2's click rate is *higher* than Q1's. Explain why that is not a regression (difficulty tier changed) and what the report rate tells you instead.
4. **Write the scorecard (1.5 h).** Three or four headline numbers with trend, a sentence on what they do not prove, the coverage gap stated plainly, and one decision you are asking for.

## Automated checks

`check_scorecard.py` recomputes the key values independently and compares them with your `metrics.json` (tolerance 0.005). It also checks the scorecard file for staff IDs.

```python
import csv, json, re, statistics, sys
def rows(p): return list(csv.DictReader(open(p)))
roster = {r["staff_id"]: r for r in rows("roster.csv")}
sim = rows("sim_events.csv")
real = rows("real_reports.csv")
m = json.load(open("metrics.json"))
DIFF = {"Q1": "easy", "Q2": "hard"}
fails = []
for q in ("Q1", "Q2"):
    d = [r for r in sim if r["quarter"] == q and r["delivered"] == "yes"
         and not (q == "Q2" and roster[r["staff_id"]]["on_leave_q2"] == "yes")]
    rep = sum(r["reported"] == "yes" for r in d) / len(d)
    clk = sum(r["clicked"] == "yes" for r in d) / len(d)
    clickers = [r for r in d if r["clicked"] == "yes"]
    rac = sum(r["reported"] == "yes" for r in clickers) / len(clickers)
    med = statistics.median(int(r["minutes_to_report"]) for r in d if r["reported"] == "yes")
    for key, want in [("report_rate", rep), ("click_rate", clk),
                      ("report_rate_among_clickers", rac), ("median_minutes_to_report", med)]:
        got = m.get(key, {}).get(q)
        tol = 0.5 if key == "median_minutes_to_report" else 0.005
        if got is None or abs(got - want) > tol:
            fails.append(f"{key}[{q}] = {got}, expected ~{want:.3f}")
    if m.get("difficulty", {}).get(q) != DIFF[q]:
        fails.append(f"difficulty[{q}] = {m.get('difficulty', {}).get(q)}, expected {DIFF[q]}")
    rq = [r for r in real if r["quarter"] == q]
    firsts = [r for r in rq if r["first_report_for_campaign"] == "yes"]
    share = sum(r["detected_first_by"] == "human_report" for r in firsts) / len(firsts)
    if m.get("real_reports", {}).get(q) != len(rq):
        fails.append(f"real_reports[{q}] = {m.get('real_reports', {}).get(q)}, expected {len(rq)}")
    got = m.get("real_malicious_share_first_detected_by_human", {}).get(q)
    if got is None or abs(got - share) > 0.005:
        fails.append(f"real_malicious_share_first_detected_by_human[{q}] = {got}, expected ~{share:.3f}")
cov = len({r["staff_id"] for r in sim}) / len(roster)
if abs(m.get("simulation_coverage", {}).get("Q2", -1) - cov) > 0.005:
    fails.append(f"simulation_coverage[Q2] expected ~{cov:.3f}")
card = sys.argv[1] if len(sys.argv) > 1 else "scorecard.md"
try:
    if re.search(r"\bS\d{3}\b", open(card).read()):
        fails.append("scorecard contains individual staff IDs")
except FileNotFoundError:
    fails.append(f"{card} not found")
print("\n".join(fails) if fails else "ALL CHECKS PASSED"); sys.exit(1 if fails else 0)
```
